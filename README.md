# FileSync 文件夹比对工具

基于 Tauri 2 + React + Rust 的桌面应用，提供两大功能：

1. **文件夹内容比对**：对两个文件夹进行深度内容比对，按 **SHA256 哈希**识别重复文件，不依赖文件名与修改时间。比对完成后可选择**一键一致化**等同步操作，让两侧文件夹内容保持一致。适用于备份核对、迁移验证、双向同步、去重清理等场景。
2. **重复文件扫描**：扫描单个文件夹（递归子目录），按 **文件大小分组预筛 + SHA256 内容确认**找出内部互相重复的文件，按重复组输出清单（完整路径 + 占用空间 + 可释放空间），并支持**一键删除**（移入 App 回收站，可随时**一键撤销**恢复到原位置）。

## 功能特性

- **内容级比对**：按 SHA256 全量哈希分组，同名不同内容、异名同内容均可正确识别
- **大小优先优化**：先比对两侧文件大小集合，大小无匹配的文件直接跳过哈希计算，速度大幅提升
- **超大文件友好**：4MB 分块读取计算哈希，内存占用稳定；超大文件不会撑爆内存
- **多核并行**：基于 rayon 的并行哈希计算，线程数等于 CPU 核心数
- **实时进度**：阶段 / 侧别 / 计数 / 百分比 / 当前文件实时推送（150ms 心跳），UI 不卡顿
- **随时可取消**：取消后输出已完成部分的结果并标记
- **四类结果视图**：重复（A∩B）/ 仅在 A / 仅在 B / 错误列表，Tab 切换
- **比对后同步操作**：比对完成后可选择后续动作，将单侧独有文件复制到另一侧
  - **一键一致化**：A 独有 → B 且 B 独有 → A，双向互补复制，使两侧内容完全一致
  - **A 独有 → B** / **B 独有 → A**：按需单向复制
  - **不做处理**：仅查看结果，关闭操作面板（可从统计栏随时重新打开）
  - 同步过程显示实时进度、可随时停止；复制保留相对目录结构，自动创建目标子目录
  - **安全不覆盖**：目标侧已存在同名（不同内容）文件时自动跳过并计入「冲突」，绝不覆盖已有数据；完成后展示复制 / 冲突 / 失败统计与明细
- **同步可撤销**：一键撤销本次比对会话内历次同步复制的文件
  - 撤销前校验目标文件大小与复制时是否一致，被修改过的文件自动保留不删，防止误删
  - 目标文件已不存在视为已撤销；删除自动顺带清理因此变空的目录（非空目录不受影响）
  - 撤销过程显示实时进度、可随时停止；失败或中途停止的条目保留在记录中，可再次执行撤销继续
  - 撤销记录保存在内存中：开始新的比对或退出应用后失效
- **重复文件扫描**（单文件夹去重）：
  - 递归遍历全部子文件夹；无权限读取 / 遍历失败的文件计入错误列表，不中断扫描
  - **两阶段确认**：先按文件大小分组，大小唯一的文件直接跳过哈希（预筛）；仅对同大小文件计算 SHA256，按哈希分组，组内 ≥ 2 个文件才判定重复——绝不凭文件名判断
  - 按重复组展示清单：组号、单文件大小、组内文件数、可释放空间、完整路径，双击行可在资源管理器中定位
  - **清理辅助**：每组默认选中除首个文件外的副本（首个按路径排序为建议保留项），支持全选 / 全不选 / 「仅保留此文件」，一键复制全部选中路径（含总占用空间）供粘贴进清理脚本
  - 重复组按可释放空间降序排列，优先清理收益最大的组
  - CSV 导出（UTF-8 BOM，Excel 打开不乱码），含分组明细、错误列表与统计
- **重复文件一键删除**（可撤销）：
  - 「🗑 删除选中副本」把选中的文件移入 **App 自管理回收站**（`<App 数据目录>/filesync-trash/`，非系统回收站），删除前逐项三重校验：必须位于扫描目录内、文件仍存在、大小与扫描时一致（防止误删与删到扫描后被修改的文件）
  - 删除过程显示实时进度、可随时「停止」；已处理的生效，未处理的保留
  - **删除完成后可一键撤销**：「↩ 撤销本次删除」或回收站列表中逐批「↩ 恢复」，文件按原路径恢复（原目录不存在会重建；原位置已有同名文件则跳过，绝不覆盖）
  - **回收站**：列出全部可撤销的删除批次（时间 / 文件数 / 大小 / 来源目录），支持「打开回收站文件夹」与「清空回收站」（永久删除，不可恢复）；批次记录持久化，重启 App 后仍可撤销
  - 撤销 / 清空同样有实时进度与停止能力；删除、撤销、清空三类任务与比对 / 同步 / 撤销同步互斥，不会并发冲突
- **CSV 导出**：UTF-8 BOM 编码，Excel 打开不乱码
- **细节交互**：双击行打开资源管理器并定位选中文件；一键复制路径 / 哈希；浅色 / 深色主题
- **异常容错**：遍历 / 读取失败的文件计入错误列表，不中断整体任务

## 环境要求

- Node.js 18+
- Rust 工具链（MSVC 目标）
- VS Build Tools 2022（勾选「C++ 桌面开发」）

```powershell
# 安装 Rust 与 VS Build Tools（如尚未安装）
winget install Rustlang.Rustup
winget install Microsoft.VisualStudio.2022.BuildTools
```

## 快速开始

```powershell
git clone https://gitcode.com/lzb759/FileSync.git
cd FileSync
npm install        # 安装前端依赖
npm run tauri dev  # 启动开发模式（热重载）
```

## 使用说明

### 文件夹比对

1. 启动应用后，分别选择需要比对的文件夹 A 与 B
2. 点击「开始比对」，等待扫描与哈希计算完成
3. 在四个结果 Tab 中查看：
   - **重复**：两侧内容完全一致的文件（按哈希分组，展示各自路径）
   - **仅在 A**：A 独有的文件
   - **仅在 B**：B 独有的文件
   - **错误**：无法读取 / 遍历失败的条目
4. 比对完整完成后，结果上方会出现「后续操作」面板，选择一种同步动作：
   - **一键一致化**：把 A 独有文件复制到 B，同时把 B 独有文件复制到 A（推荐用于双向备份对齐）
   - **A 独有 → B** / **B 独有 → A**：仅单向复制某一侧的独有文件
   - **不做处理**：关闭面板；如需再次操作，点击统计栏右侧「同步操作」重新打开
   - 同步时显示实时进度并可「停止同步」；完成后展示复制 / 冲突跳过 / 失败统计，可展开查看明细
   - 目标侧已存在同名（不同内容）文件会作为冲突跳过，**不会覆盖**
5. **撤销同步**：点击「撤销同步（N 个）」可删除本次比对会话内、历次同步复制到对侧的文件
   - 撤销前校验文件大小：与复制时不一致（可能已被修改）的文件自动保留，不会误删
   - 撤销时显示实时进度并可「停止撤销」；停止或失败后再次点击可继续撤销剩余部分
   - 撤销完成后展示删除 / 已不存在 / 已修改保留 / 失败 / 清理空目录统计
6. 可随时点击「停止」中断比对任务，已完成的比对结果仍然保留（被中断的比对不提供同步操作）
7. 点击「导出 CSV」保存结果，双击任意条目可在资源管理器中定位该文件
8. 同步或撤销完成后，结果列表仍为同步前快照，建议重新比对一次以验证两侧状态

### 重复文件扫描

1. 点击顶部「🔍 重复文件扫描」切换到扫描模式
2. 选择目标文件夹（递归包含全部子文件夹），点击「开始扫描」
3. 扫描分两阶段：先递归枚举文件并按大小分组预筛，再对同大小文件并行计算 SHA256 确认内容一致
4. 结果按重复组展示（可释放空间大的组排前面）：
   - 组头显示：组号、单文件大小 × 文件数、可释放空间、哈希值
   - 组内每行显示：完整路径、占用空间；**双击行**在资源管理器中定位
   - 每组默认选中除首个文件外的副本（首个文件标记「保留」，为建议保留项）；可用行内「仅保留」把某个文件设为保留项，或用组头「全选 / 全不选」调整
5. 「复制选中路径」一键复制全部选中副本的路径（附总占用空间），可粘贴进清理脚本或资源管理器地址栏批量处理
6. **一键删除**：点击「🗑 删除选中副本（N 个 · 大小）」，确认后选中的重复副本被移入 App 回收站
   - 删除过程有实时进度，可随时「停止」；完成后展示删除 / 释放空间 / 跳过 / 失败统计
   - 删除后结果列表自动刷新：不足 2 个副本的组自动消失，可释放空间实时重算
   - 删除完成后可通过消息条上的「↩ 撤销本次删除」立即恢复
7. **回收站与撤销**：
   - 删除完成的批次会出现在「🗑 回收站」区域（时间 / 文件数 / 大小 / 来源目录），点击「↩ 恢复」即可把该批文件恢复到原位置；原位置已有同名文件会跳过（不覆盖）
   - 「打开回收站文件夹」可直接查看暂存的文件；「清空回收站」为永久删除，**不可恢复**，请谨慎使用
   - 回收站记录持久化：重启 App 后历史批次仍可撤销
   - 注意：回收站中的文件占用磁盘空间，确认无需恢复后请及时清空
8. 点击「导出清单 CSV」保存完整清单（分组明细 + 错误列表 + 统计）
9. 无权限读取或遍历失败的文件不会中断扫描，可在「读取失败」Tab 查看明细
10. 大文件夹扫描时界面保持响应，可随时「停止扫描」，已完成的组仍会输出

## 项目结构

```
FileSync/
├── src/                          # 前端：UI、参数输入、结果展示
│   ├── App.tsx                   # 主界面：模式切换（比对/重复扫描）、事件订阅、开始/停止/导出、同步与撤销接线
│   ├── types.ts                  # 与 Rust serde 对应的结果/同步/撤销/重复扫描/删除回收站类型
│   └── components/
│       ├── FolderPicker.tsx      # 文件夹选择
│       ├── ProgressPanel.tsx     # 进度条 + 当前文件 + 停止（比对/扫描通用，title 可配置）
│       ├── SyncPanel.tsx         # 比对后操作面板（一致化/单向复制/撤销/不做处理）
│       ├── ResultsView.tsx       # 比对结果 4 Tab 视图
│       └── DupScanView.tsx       # 重复文件扫描视图（统计/重复组清单/选中副本/一键删除/回收站与撤销）
└── src-tauri/                    # 后端：全部文件 IO / 哈希 / 遍历 / 同步与撤销 / 重复扫描与回收站
    └── src/
        ├── scanner.rs            # 递归枚举、4MB 分块 SHA256、rayon 并行
        ├── compare.rs            # A∩B / A-B / B-A 分类
        ├── dup_scan.rs           # 重复文件扫描：大小分组预筛 + 并行哈希 + 按哈希分组；删除/撤销后的结果刷新
        ├── dup_trash.rs          # 重复文件删除与撤销：App 自管理回收站、批次持久化、恢复/清空
        ├── sync.rs               # 同步动作：双向一致化 / 单向复制（冲突跳过）+ 撤销（大小校验/空目录清理）
        ├── commands.rs           # start/stop_compare、start/stop_dup_scan、delete_dup_files/stop_dup_delete、undo_delete_dup/purge_trash/list_delete_batches/open_trash_dir、export_dup_csv、apply_sync_action/stop_sync、undo_sync/stop_undo、export_csv、open_in_explorer
        ├── csv_export.rs         # UTF-8 BOM CSV 导出（比对结果 / 重复文件清单）
        └── state.rs              # 取消/运行标志 + 结果/根目录缓存 + 撤销记录 + 扫描结果缓存
```
